# Project Planning

One of the most important steps in ensuring successful project delivery is effective planning.

Projects need robust planning to:

- Define what is included and excluded from the project
- Identify the resources needed to complete the project
- Establish a timeline for completion

When organisations outsource project work, they usually require a project plan to be submitted before work can begin. This helps ensure that the project is feasible and that the organisation has the resources to complete it.

# Tasks and Subtasks

Projects are a collection of **tasks**, **subtasks**

- **Task:** A task is a specific piece of work that needs to be completed as part of a project.
  - A distinct and manageable unit of work that contributes to the overall project goals.
- **Subtask:** A subtask is a smaller, more specific component of a task that helps break down the work into manageable parts.
  - Subtasks break down a task into smaller, actionable steps, making it easier to track progress and allocate resources effectively.
  - It is possible to have multiple levels of subtasks, depending on the complexity of the task.

# Milestones

Throughout the project, key **milestones** occur:

- **Milestone:** A milestone is a significant event or achievement within a project that marks the completion of a major phase or deliverable.
  - Milestones help track progress and celebrate achievements
  - Milestones do not have a duration - they represent a *specific point in time.*

# Example and Practice

::left::

### Example

**Task:** Create a website for a local business
**Subtasks:**

- Design the website layout and user interface
- Develop the website using HTML, CSS, and JavaScript
- Test the website for functionality and usability

**Milestones:**

- Website design approved by the client
- Website development completed and tested
