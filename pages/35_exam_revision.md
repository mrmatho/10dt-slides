# Exam Structure

- 10 minutes reading time
- 60 minutes writing time

::left::

## Section A - Multiple Choice (10 marks)

- 10 multiple choice questions
- 4 options per question
- 1 mark per question (10 marks total)
- Answer on the separate answer sheet

::right::

## Section B - Case Study (40 marks)

- Separate case study information booklet provided
- Short answer questions - based on the info in the case study booklet
- Variable marks per question (1-3)

# Topics Covered

The exam will cover essentially everything we worked on this semester.

::left::

- Terminal
  - Recalling basic commands
  - Reading and interpreting a terminal script
  - Advantages and disadvantages of using the terminal
- Cybersecurity
  - Threats, vulnerabilities, and risks
  - Security controls
  - Websites and URLs
  - Security Principles

::right::

- Emerging Technologies
  - What makes a technology "emerging"?
  - Applying emerging technologies to a scenario
  - Ethical and social implications of emerging technologies
  - Problem Solving Methodology (Analysis, Design, Implementation, Evaluation)
- Web Applications
  - HTTP basics (GET, POST, Response codes)
  - CRUD operations and routing processes
  - Templates and logic in web applications
  - Testing and debugging web applications
